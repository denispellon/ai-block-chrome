# AI Block for Google Overviews

This extension just deactivate AI Overviews during Google Search. It modifies the URL so the IA Mode is disable. 
In all possible cases, the research is block on server-side. If not (it appends sometimes), it just erase it from your page so you are not disturbed.

This is the Google Chrome version, you will need to add it by yourself as I do not want to pay fees (sorry...)
Here is a step-by-step:
- Download the repo and extract it somewhere you will not move it afterward
- Open Google Chrome and type *chrome://extensions* in address bar
- Toggle the Developer Mode switch located on the top-right corner of the page
- Click on *load unpacked* button on top-left toolbar
- Navigate to the download directory containing the **manifest.json file**, then click *Select folder*

Sometimes (every 14 days), Chrome is asking if you want to keep the extension as it is not "official". Just click *yes*.

Enjoy !
